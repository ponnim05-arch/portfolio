# 🚀 Kumar Ponmani — AI & Machine Learning 3D Portfolio

A modern, interactive 3D developer portfolio built with **React**, **Vite**, **Framer Motion**, and **Lucide React**. Showcases full-stack AI/ML applications, autonomous agents, computer vision models, NLP systems, technical skills, experience, and educational background.

---

## 🌟 Key Features

- **3D Magnetic Tilt Cards**: Smooth physics-based cursor tilt interactions and dynamic perspective transformations.
- **Interactive Cursor Glow**: Real-time radial glow effect following pointer coordinates.
- **GitHub Projects Showcase**: Highlighting public AI/ML repositories from [@ponnim05-arch](https://github.com/ponnim05-arch) with interactive category filters, repository links, and tech badges.
- **Technical Toolbox**: Interactive breakdown of skills spanning Machine Learning, Generative AI, Deep Learning, Backend APIs, and CS fundamentals.
- **Responsive & Accessible**: Optimized for desktop, tablet, and mobile screens with dark glassmorphism aesthetic.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 8, Framer Motion
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Glassmorphism, CSS Variables, Responsive Grid/Flexbox)
- **Deployment**: Vite Build Pipeline

---

## 📦 Project Setup

### 1. Clone Repository
```bash
git clone https://github.com/ponnim05-arch/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install --legacy-peer-deps
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
